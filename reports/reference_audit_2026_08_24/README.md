# Reference Audit 2026-08-24

최신 IEEE Access 원고의 참고문헌 46개를 전수 감사한 산출물이다.

## 공개 저장소 포함 파일

- `reference_full_audit_ko.md`: 전체 한글 감사 보고서
- `reference_full_audit.csv`: 참고문헌 46개별 접근 수준, 서지 판정, 본문 주장 적합성
- `reference_issues.csv`: 원고 수정 우선순위 목록
- `download_targets.tsv`: 감사에 사용한 공식 source target 목록
- `logs/download_results.tsv`: 최초 HTTP 다운로드 결과

## 공개 저장소 제외 파일

`downloads/`와 `extracted/`에는 publisher PDF, 웹 전문, 추출 텍스트가 포함되어 있어 저작권과 재배포 조건을 고려해 GitHub에는 커밋하지 않는다. 해당 파일은 연구자의 로컬 감사 증거로만 보관한다.

보고서에서 `전문 PDF`, `공식 웹 전문`, `공식 초록`, `공식 서지`를 구분한 이유는 접근하지 못한 전문을 읽은 것처럼 과장하지 않기 위해서다.
