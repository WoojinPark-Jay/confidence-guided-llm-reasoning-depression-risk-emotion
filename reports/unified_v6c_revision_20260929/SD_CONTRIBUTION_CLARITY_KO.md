# SELF-DISCOVER 설계 기여와 실행 흐름 설명 보강

## 이번 수정 목적

최종 v6c를 단순히 SELF-DISCOVER를 사용한 실험으로 소개하지 않고, 연구자가 구체화한 설계와 이를 뒷받침하는 관측 결과를 연결했다. 동시에 공통 계획을 누가, 언제, 무엇을 보고 생성하는지 본문과 부록 그림에서 바로 파악할 수 있게 정리했다.

이번 변경은 원고 설명과 도식의 개선이다. 새 실험, 수치 수정, 프롬프트 변경은 없다. 9,000건 추가 평가는 아직 완료되지 않았으므로 최종 모델의 추가 결과로 넣지 않았다.

## 논문에서 어필하는 기여

1. 보정된 분류기 신뢰도로 낮은 확신도의 사례만 원문 기반 LLM 재평가에 연결하는 전체 파이프라인.
2. 기존 SELF-DISCOVER의 틀을 유지하면서 감정 분류에 필요한 판단 항목과 실행 지침을 구체화한 설계.
3. 동일한 라우팅 사례에서 모델과 재평가 방식을 비교하고, 오류 수정과 신규 오류를 함께 평가한 실험.

공통 계획 생성이나 캐시 자체를 새로 발명했다고 주장하지 않는다. 최종 계획 생성에는 개별 평가 게시물이나 정답이 들어가지 않지만, 이것이 프롬프트 개발에서 평가 결과를 확인한 이력까지 없애는 뜻은 아니다. 관련 기존 한계 문장은 유지한다.

## 핵심 흐름

```text
연구자가 과제 설명·분류 정책·추론 모듈·실행 지침 작성
  ↓
분류 시작 전 코드가 모델별 저장 계획 존재 여부 확인
  ├─ 있음: 저장 계획 불러오기
  └─ 없음: LLM이 과제 설명·정책·모듈을 보고
           SELECT → ADAPT → IMPLEMENT 수행 → 코드가 계획 저장
           (개별 게시물·정답·Phase 1 예측은 입력하지 않음)
  ↓
게시물마다 원문 + 저장 계획 + 고정 실행 지침을 LLM에 입력
  ↓
새로운 분석과 최종 라벨 생성
  ↓
코드에서 파싱. 실패하면 기존 Phase 1 예측 유지
```

Llama 2와 Llama 3는 각각 자기 계획을 만든다. 각 모델은 자기 계획을 Reddit과 Mixed Emotion에 재사용한다. 재사용하는 것은 판단 절차이며 이전 게시물의 답이 아니다.

## 해석 범위

- 최종 Llama 3 SD는 최종 여섯 조건 중 두 데이터셋에서 최고 관측 성능이다.
- 기존 사용자 SD 대비 최종 v6c는 Llama 3에서 두 데이터셋 모두 향상했지만, Llama 2 Reddit에서는 낮아졌다.
- 공통 계획, 모듈, 실행 지침 등이 함께 바뀌었으므로 캐시 또는 특정 지침 하나의 인과효과로 설명하지 않는다.
- 프롬프트의 단계 수·근거 검토 요구는 지시이며 실제 출력에서 항상 준수된다는 의미가 아니다. 실제 생성 계획은 수정하지 않고 유지한다.

## 변경하지 않은 자료

기존 아키텍처 원본 그림, 실제 프롬프트와 모델 생성 계획, 12조건 집계 및 통계, Phase 1 수치와 실험 결과는 그대로 유지한다. 동료의 원시 CSV 확보와 방법 간 대응 검증 등 남은 실험 검토를 완료한 것으로 표시하지 않는다.
