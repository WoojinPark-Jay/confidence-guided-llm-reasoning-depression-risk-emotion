# 원래 논문 스타일 기준 시각 품질 복원

공동 검토용 · 2026-09-29

## 수정 기준

9월 12일 검토 원고의 색상, Times 계열 글꼴, 표 구성과 벡터 그림을 기준으로 맞췄다. 최신 실험 결과와 프롬프트 원문은 유지하고 시각적 표현과 배치를 수정했다.

## 수정한 부분

| 영역 | 이번 수정 |
|---|---|
| 그래프 색상·글꼴 | 원래의 청색·회청색·회색 계열과 Times New Roman으로 통일 |
| 그림 파일 | 글자를 선택할 수 있는 벡터 PDF 사용. 편집용 SVG와 450 dpi PNG도 생성 |
| 혼동행렬 | 부록에서 본문 결과 영역으로 이동. 원래처럼 건수와 행 기준 비율을 함께 표시하고 공통 색상 척도 사용 |
| Calibration 그림 | 신뢰도 곡선·보정 지표 감소·위험-커버리지의 원래 3패널 구성 복원 |
| Routing 그림 | 확신도 분포·오류 포착·라우팅 집합의 오류 집중도를 최신 Phase 1 예측으로 다시 작성 |
| 최종 성능·오류 그림 | 늘어난 6조건을 읽을 수 있도록 데이터별 패널로 정리. 원래 점/선·양방향 막대 스타일을 사용하고 수정·신규 오류·순수정 표시 |
| 표 | 최신 결과 표의 글씨 크기와 행 간격을 조정하고 본문·부록의 표 너비를 통일 |
| 프롬프트 부록 | 작은 고정폭 코드 박스 대신 읽기 쉬운 본문 계열 글꼴과 구분선 사용. 실제 프롬프트 문자열은 변경하지 않음 |
| 방법 요약 | 원래 부록의 요약표 형식을 복원하고 최종 Direct·CoT·SD의 입력, 처리, 출력 관계를 표시 |
| SD 흐름도 | 원래 청회색 벡터 스타일을 참고해 최종 공통 계획 생성·재사용 방식으로 갱신 |
| 페이지 구성 | 결과 그림이 참고문헌 뒤로 밀리지 않도록 정리. 표 제목과 표, 모델별 실제 계획이 불필요하게 갈라지는 문제 수정 |
| 메인 아키텍처 | 기존 원본 PDF와 draw.io 유지. 문구 변경은 별도 아키텍처 수정 가이드에 따라 진행 |

## 수치와 자료 보존

- 전체 12조건 결과·통계 CSV와 최신 Phase 1 집계는 시각 수정 전후 동일하다.
- 프롬프트 텍스트 파일과 기록된 실제 계획은 원문 그대로다.
- 메인 아키텍처 PDF는 기존 원본과 동일하다.
- 현재 본문 혼동행렬은 행별 예측이 확인된 **최종 Phase 1** 결과다. 최종 SD 재평가 후 혼동행렬은 결과 CSV 네 개를 받은 뒤 추가한다. 집계 정확도만으로 행렬을 추정하거나 구형 행렬을 재사용하지 않았다.

앞으로 수치가 바뀔 때도 이 글꼴·색상·표 스타일을 기준으로 유지한다. 현재 원고는 최신 결과를 반영한 공동 검토본이며, 남은 행별 결과 대조와 제출 정보 확정은 기존 작업 목록을 따른다.
