# 논문 업데이트 현황과 마무리 계획

공동 검토용 · 2026-09-29

## 현재 상태

**계획한 모델·방법 비교 실험은 완료했고, 결과를 반영한 원고를 작성했다. 다음 단계는 저장된 결과를 대조하고 표·통계·그림을 확정하는 일이다.**

Llama 2·Mistral의 분류 실험이나 DistilBERT 학습을 다시 할 필요는 없다. 현재 추가로 받아야 할 핵심 자료는 최종 SELF-DISCOVER(v6c)의 게시글별 결과 CSV 네 개다.

## 한눈에 보는 진행 상태

| 상태 | 항목 | 다음 행동 |
|---|---|---|
| 완료 | 최종 실험 구조, 12조건 집계 결과, 프롬프트와 방법론을 원고에 반영 | 공동 리뷰 |
| 완료 | 기존 컬러톤·글꼴·벡터 그림 스타일 복원, 본문 Phase 1 혼동행렬, 부록 가독성 정리 | 복원본을 기준으로 이후 수정 |
| 완료 | 24쪽 PDF 렌더링과 배치 검토 | 최종 자료 반영 후 다시 확인 |
| 파일 전달 대기 | v6c 결과 CSV 네 개 | 자료 담당이 기존 저장 파일 전달 |
| 파일 수령 후 | 12조건 행별 수치 대조, 방법 간 통계, 최종 SD 혼동행렬·클래스별 F1 | 분석 담당이 일괄 검증 후 원고 반영 |
| 기록 정리 필요 | 계획 JSON, 실행 설정·모델 식별 기록 | 있는 파일부터 묶고 불명확한 항목만 확인 |
| 공동 결정 필요 | 아키텍처 최종 문구, 저자 정보, 공개 범위 | 최종 검토 때 확정 |

여기서 '완료'는 해당 원고 반영 또는 시각 검토가 끝났다는 뜻이다. 아직 전달되지 않은 v6c 원시 결과 전체까지 검증했다는 뜻은 아니다.

## 최종 실험 구조

1. 완료된 분류 실험에서 선택한 설정의 DistilBERT 저장 모델(seed42)을 사용한다.
2. 모델의 확률을 보정하고, 확신도가 낮은 글만 LLM으로 넘긴다.
3. Llama 2와 Llama 3에서 각각 Direct, CoT, 최종 SELF-DISCOVER를 비교한다.
4. Reddit과 Mixed Emotion에서 같은 비교 구성을 평가한다. 총 12조건이다.

최종 SELF-DISCOVER는 **v6c**다. 이전 SD와의 비교는 부록에서 설계 차이를 설명하는 데만 사용한다. 여러 요소가 함께 바뀌었으므로 특정 요소 하나만의 효과를 검증한 실험으로 설명하지 않는다.

| 기존 분류 실험 | DistilBERT·Llama 2·Mistral의 3시드 비교와 Phase 1 GPU 효율성 자료 유지 |

| 본문 배치 | 최신 Phase 1 혼동행렬을 본문으로 이동하고 calibration·routing 그림 구성 복원 |

최종 Phase 1 예측은 행별로 재집계했다. **v6c 수치는 실행 노트북과 공동연구 요약을 근거로 반영했으며, 결과 CSV 전체 대조는 남아 있다.**

이전 모델의 9,000건 추가평가와 구형 오류 사례는 새 최종 모델의 검증 결과로 섞지 않았다. 기존 자료는 별도로 보존한다.

## 핵심 결과

현재 보고된 집계 기준이다. 정확도는 라우팅된 글만이 아니라 전체 평가셋 기준이다.

| 데이터 | 전체 글 | 재평가 | Phase 1 정확도 | Llama 3 최종 SD 정확도 | 수정 | 신규 오류 | 순수정 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Reddit | 12,000 | 218 | 96.9167% | 97.2000% | 72 | 38 | +34 |
| Mixed Emotion | 300 | 86 | 83.6667% | 92.6667% | 28 | 1 | +27 |

Llama 3 최종 SD는 두 데이터셋에서 최종 비교 조건 중 가장 높은 관측 정확도를 보였다. Llama 2의 Reddit 결과에서는 Direct가 SD보다 높으므로, 모든 모델에서 SD가 항상 최고였다고 쓰지는 않는다.

Mixed Emotion의 **신규 오류 1건**은 원래 맞았던 예측을 틀리게 바꾼 건수다. **파싱 실패 1건**은 응답에서 라벨을 추출하지 못한 건수로, 서로 다른 개념이다. 파싱 실패는 기존 Phase 1 예측을 유지하는 규칙으로 처리한다.

## 남은 작업 순서

### 1. 최종 SD 결과 파일 전달

자료 담당은 모델·데이터별 `sd_v6c_compact_results.csv` 네 개를 전달한다. 새로 실행하지 않고 저장된 파일을 보내면 된다.

계획 JSON 두 개와 실행 설정·로그는 있으면 함께 전달한다. 별도 설정 파일이 없다면 실행 노트북으로 확인 가능한 내용을 정리한다. 파일명과 폴더 위치는 [파일 공유 요청서](COLLABORATOR_FILE_REQUEST_KO.md)에 모았다.

### 2. 게시글별 결과 대조

분석 담당은 같은 게시글 ID끼리 Phase 1·Direct·CoT·SD 결과를 맞추고 다음을 확인한다.

- 필요한 글이 모두 있는지, 중복은 없는지
- 정확도·Macro F1·수정·신규 오류가 현재 표와 일치하는지
- 파싱 실패와 기존 라벨 복구가 각 방법에서 어떤 규칙으로 처리됐는지
- 최종 혼동행렬과 클래스별 F1이 전체 예측과 일치하는지

잔여 파싱 실패는 현재 규칙대로 유지한다. 실패한 글만 재생성하거나 정답을 보고 답을 채우지 않는다.

### 3. 방법 간 통계 비교

현재 통계표의 질문은 **각 방법이 Phase 1보다 얼마나 달라졌는가**다. 남은 질문은 **SD가 CoT 또는 Direct와 같은 글에서 어떻게 달랐는가**다.

정확도 합계만으로는 두 방법이 어떤 글을 함께 맞히거나 다르게 틀렸는지 알 수 없다. 게시글별 예측을 받은 뒤 대응 비교를 계산하고 원고의 표현을 결과에 맞춘다.

관측 정확도가 가장 높다는 설명과 통계적으로 유의하게 더 좋다는 설명은 구분한다. 방법 간 유의한 우위를 주장하려면 해당 검정이 필요하다. 프롬프트 탐색에서 확인한 성능 순위는 별도의 독립 검증 결과와도 구분한다.

### 4. 실행 설정과 재현 자료 정리

코드·저장 기록에서 생성 길이, 실제 재사용 계획, 모델 버전, 긴 입력 처리 방식을 대조한다. 현재 원고에는 최종 SD 생성 상한이 Llama 2는 1,024, Llama 3는 1,536이라는 차이를 명시했다.

모델 파일의 해시값은 같은 저장 모델인지 식별하는 기록이다. 추가하면 재현에 도움이 되지만 이를 위해 재학습할 필요는 없다. 모델 가중치 전체를 다시 요청해야 한다는 뜻도 아니다.

### 5. 그림과 제출 정보 마무리

- 기존 아키텍처의 최종 방법명, 공통 계획 재사용, 실패 시 처리 등의 문구를 [그림 수정 가이드](ARCHITECTURE_EDIT_GUIDE_KO.md)에 맞춰 수정한다.
- 새 그림을 원고에 교체하고 현재의 검토용 그림 안내 문구를 제거한다.
- 저자·소속·연락처·연구비·데이터와 코드 공개 범위를 공동으로 확정한다.
- 저자란의 임시 문구를 실제 정보로 바꾼다. 권호·페이지 등 출판사가 정하는 정보는 투고 템플릿 지침에 맞춘다.
- 최종 PDF에서 본문·부록·표·그림의 수치와 배치를 대조한다.

## 이번 마무리에 포함하지 않는 일

- 완료한 Llama 2·Mistral 분류 실험의 재실행
- DistilBERT 재학습이나 별도 운영 모델 추가
- 탐색한 모든 프롬프트 버전을 본문에 나열하는 작업
- 잔여 파싱 실패를 없애기 위한 해당 사례만의 재생성
