# 본문·부록 설명 및 SD 흐름도 보강

공동 검토용 · 2026-09-29

## 이번 수정의 목적

실험 결과는 유지하면서 독자가 방법을 이해하고 실제 프롬프트와 평가 결과까지 따라갈 수 있도록 설명을 보강했다. 부록도 본문과 같은 수준의 글꼴·색상·표·벡터 그림 품질을 유지한다.

## 주요 변경

| 영역 | 이전 | 이번 보강 |
|---|---|---|
| 기여도 | 기여 항목 나열 | 각 기여를 분류 효율성·라우팅·수정/신규 오류·모델/방법 비교 근거에 연결 |
| 본문 SD | 단계 이름과 실행 지침 중심 | 공통 절차를 만드는 단계와 각 글에 적용하는 단계를 먼저 설명 |
| 캐시드 플랜 | 저장과 재사용을 짧게 언급 | 답이 아니라 모델이 생성한 분석 절차를 저장하며 매 글마다 새 응답을 생성한다고 설명 |
| 역할 구분 | 계획과 고정 지침의 경계가 약함 | 연구자가 제공한 정책·모듈·실행 지침, 모델이 만든 계획, 게시글 원문의 역할 구분 |
| 부록 SD 그림 | 축약된 단계 흐름 | 계획 생성과 재사용 범위, 글별 입력, 근거 점검, 모델 출력, 코드의 파싱·fallback을 분리 |
| 프롬프트 안내 | 원문 템플릿 위주 | 단계별 목적·입력·출력·실행 시점 설명 추가. 실제 프롬프트 파일은 그대로 유지 |
| 처리 예시 | 흐름을 한 번에 읽을 예시가 없음 | 설명용 문장으로 주체·시점·증거·라벨 처리 흐름 설명. 실험 사례나 실제 모델 응답이 아님을 명시 |
| 이전 SD와 비교 | 짧은 설명과 결과표 | 구조 비교표 D1과 성능표 D2로 분리. 네 조건 중 세 조건 개선, Llama 2 Reddit 하락도 유지 |
| 통계 부록 | 계산 절차 위주 | 각 행의 비교 대상, pp·신뢰구간·exact p·Holm p의 의미를 먼저 설명 |
| 논의 | 결과 요약 문단 | 분류 효율성, 선택과 수정의 차이, 모델/방법 비교의 해석을 구분 |
| 표 식별 | B·C·F 부록에서도 A 계열 표 이름 사용 | 해당 부록에 맞춰 B1·C1·F1로 정리하고 본문 참조도 갱신 |
| 생성 데이터 부록 | 생성 프롬프트가 작은 글씨의 두 칸 배치 | 글씨를 키우고 전체 너비의 두 문단으로 변경. 생성 지침 내용은 유지 |

## 부록 그림을 바꾼 이유

이전 그림은 개별 글에서 SELECT·ADAPT·IMPLEMENT를 거쳐 계획을 만드는 구조를 보여줬다. 최종 v6c는 과제 공통 계획을 모델별로 만들어 저장하고, 이를 각 글에 적용한다. 따라서 입력 위치와 재사용 경로를 수정해야 했다.

이번에는 단순히 새 그림으로 교체하는 데 그치지 않고, 기존 청회색·Times 계열 스타일 안에서 단계별 입력과 출력의 관계를 자세히 표시했다. 점선은 저장한 계획의 재사용, 실선은 단계 사이의 입력·출력 전달이다. 메인 아키텍처 원본은 그대로 유지했다.

## 바꾸지 않은 것

- 12조건의 성능·통계 집계와 Phase 1 예측 집계.
- 실제 Direct·CoT·SD 프롬프트 및 노트북에서 확보한 모델별 계획 원문.
- 최종 SD는 v6c로 사용하며 중간 v6는 비교표에 추가하지 않는 원칙.
- 파싱 실패 시 Phase 1 예측을 유지하는 평가 규칙.
- 원시 CSV 네 개 확보 후 행별 대조·방법 간 검정·최종 SD 혼동행렬을 마무리하는 작업 순서.

구조 비교는 여러 요소가 함께 달라진 설계 비교다. 캐싱 하나가 성능 개선을 일으켰다는 주장이나 측정하지 않은 추론 비용 절감 주장은 추가하지 않았다.
